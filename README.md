# Proje Hakkında

PrLeagueX, profesyonel futbol ligi süreçlerini dijital ortama taşıyan, kullanıcı deneyimi ve yönetim kolaylığı odak alınarak geliştirilmiş modern bir **League Management Platform** projesidir.

Proje geliştirilirken **gerçek dünya senaryoları**, **ölçeklenebilirlik**, **bakım kolaylığı**, **performans optimizasyonu**, **clean code prensipleri** ve **katmanlı mimari yaklaşımı** temel alınmıştır.

Tüm veri akışı **RESTful Web API** mimarisi ile yönetilmiş, veri transfer süreçlerinde **DTO Pattern**, nesne dönüşümlerinde **AutoMapper**, veri erişim süreçlerinde ise **Repository Pattern** kullanılmıştır.

MVC katmanı API servislerini **HttpClient** ile consume ederek modern ve loosely coupled bir yapı oluşturulmuştur.

## ⚽ Match System

Maç yönetim modülü ile lig içerisindeki tüm karşılaşmalar detaylı şekilde planlanabilir ve yönetilebilir.

• Fikstür oluşturma  
• Haftaya göre filtreleme  
• Tarih bazlı listeleme  
• Maç durumu yönetimi  
• Skor güncelleme  
• Ev sahibi / deplasman yönetimi  
• Stadyum bilgisi entegrasyonu  

---

## 🔥 Match Events

Maç içerisinde gerçekleşen tüm olaylar dakika bazlı olarak timeline sistemi ile yönetilir.

• Gol  
• Sarı kart  
• Kırmızı kart  
• Oyuncu değişikliği  
• Dakika bazlı timeline gösterimi  
• Takım bazlı olay yönetimi  
• Maç detay ekranı entegrasyonu
